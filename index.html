FAQ / Aide

Comment créer un QR code ?

Cliquez sur "Créer un code QR" dans la barre latérale. Glissez votre fichier (image, PDF, Word…), choisissez la durée d'hébergement et cliquez sur "Générer".

Quelle est la durée d'hébergement ?

~1 heure : hébergement via tmpfiles.org, pour un partage rapide.
Permanent ♾ : hébergement via tmpfiles.org longue durée. Le QR reste valide tant que le lien est actif.

L'application est-elle gratuite ?

Oui, totalement gratuite. Pas d'abonnement, pas de limite d'utilisation. Toutes les données sont sauvegardées localement sur votre navigateur.
